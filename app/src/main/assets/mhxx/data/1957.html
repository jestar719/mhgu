铳枪[攻击]

动作名称 操作方法 系統
踏步突刺上挑 推动滑杆并按 X　或者　纳刀移动中按 X 切断
冲刺突刺上挑 推动滑杆并按 X 切断
水平突刺1・2发目 X 或者　跳跃炮击后着地时按 X 切断
挑飞上斩1・2・3发目 X+A 或者 跳跃炮击后着地时按 X+A 切断
防御突刺1・2・3发目 R＋X　或者　炮击（上）或者炮击（斜上）后按 X 切断
叩击 水平突刺2回目的后按 X 切断
全弹射击 叩击后按 A 固定
龙击砲 叩击后按 A + X 或者 防御中按 A + X 固定
炮击（前・斜上・上） A 固定
蓄力炮击 炮击后按 R + A 防御突刺后按 R + A 挑飞上斩后按 R + A 前方突刺后按 R + A 踏步突刺上挑后按 R + A 固定
踏步炮击 踏步突刺上挑或者冲刺突刺上挑中、攻击判定出现前按 A　或者滑杆R＋A 固定
跳跃炮击 从高低差上方滑杆＋R＋A落下 固定
跳跃突刺 跳跃中按 X 切断
跳跃叩击 纳刀且跳跃中按 R + X + A，或跳跃炮击后在空中按 X 切断
跳跃装填叩击 从高低差上方以踏步突刺上挑或冲刺突刺上挑落下 切断
装填 防御中按 A，或步伐后按 A -
快速装填 炮击后按 A 或者 跳跃炮击后着地时按 A -
防御 R　或者　纳刀中按 R＋A　或者　纳刀移动中按 R＋X+A -
